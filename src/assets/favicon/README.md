# Favicon — Longatte

Anneau de progression seul (le O du wordmark). Arc à 75 %, départ à 12 h, extrémités arrondies.

## Fichiers
- favicon.svg — vectoriel, usage principal
- favicon-dark.svg — variante inverse (piste #374151, arc #F9F9FB)
- favicon-16/32/48.png — tailles classiques (trait épaissi à 16 px)
- favicon-192/512.png — Android / PWA
- apple-touch-icon-180.png — pastille ardoise, anneau blanc brume
- og-tile-512.png — tuile réseaux sociaux
- site.webmanifest

## À coller dans le <head>
```html
<link rel="icon" href="/favicon/favicon.svg" type="image/svg+xml">
<link rel="icon" href="/favicon/favicon-32.png" sizes="32x32" type="image/png">
<link rel="apple-touch-icon" href="/favicon/apple-touch-icon-180.png">
<link rel="manifest" href="/favicon/site.webmanifest">
<meta name="theme-color" content="#111827">
```
